## 2024-05-18 - Replacing `yield from` recursion with an explicit stack for hot-path AST traversal
**Learning:** In deeply recursive AST operations within `wardline` (like `iter_calls_in_function_body`), using recursive functions with `yield from` can incur significant overhead due to Python function calls and generator delegation. An explicit stack manually tracking the nodes in reverse order provides the exact same traversal pattern without the recursion overhead, leading to ~25% performance improvement on large AST structures like standard library modules.
**Action:** When implementing deep AST traversals, utilize explicit stack loops via lists and handle traversal order by pushing elements using `reversed()` to guarantee structural parity with previous iterations while drastically saving execution time.
