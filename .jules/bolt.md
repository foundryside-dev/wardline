## 2025-02-18 - Stack-based hot-path AST traversal
**Learning:** In the `wardline` codebase, replacing recursive `yield from` with explicit stack traversal using `yield` in hot-path static analysis helpers (like `iter_calls_in_function_body`) yields significant speedups (e.g. ~1.5x for ast.Call node resolution). Using `type(node) is/in` over `isinstance()` gives a slight performance edge. It's critical to append children explicitly in reversed order (so they pop correctly) rather than doing eager list appends (`list.append()`).
**Action:** When implementing new AST node traversal in static analysis pipelines, avoid `yield from` recursion. Instead, use an explicit list acting as a stack, iterate in reversed order over child elements to maintain correct processing order, and yield items directly.
